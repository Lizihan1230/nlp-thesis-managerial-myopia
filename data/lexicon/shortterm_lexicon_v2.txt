# 短期视域词典 v2.0  ——  经"라이内容效度检验"修订后的版本
# ==================================================================
# v1.0 的失败（写进论文 5.2.2，作为"测度为什么要迭代"的证据）：
#   初次人工判读发现大量误命中，且误命中高度集中于少数高频词：
#     短期 → 短期借款(会计科目)          占该词命中 73%
#     暂时 → 闲置募集资金暂时补充流动资金 占该词命中 82%
#     临时 → 临时股东大会/董事会(治理术语)、临时键合(半导体工艺)
#     应急 → 应急救援/应急体系/应急管理局(行业与政务表述)
#     眼前 → 眼前节(眼科医学名词)
#   结论：v1.0 **未通过内容效度检验**，须回到第三步重构（见课件 Step⑤→Step③ 回路）
#
# v2.0 第二轮修订（第二轮人工判读后）：
#   - 停用词表中"股东大会/董事会"等曾被误列为停用词，导致"临时股东大会"
#     被拆成无上下文的孤立词而无法剔除；已将治理类实词移出停用词表
#   - 删除"暂时/暂时性/临时的"：其命中 90% 以上来自"募集资金暂时(性)补充
#     流动资金""可抵扣暂时性差异"两类法定披露套话，剥离成本高于保留收益
# v2.0 的修订规则：
#   R1 邻近剔除：命中词的前/后邻词若落入该词的"中和语境表"，则不计入
#   R2 删除不可救药词：语境无法剥离的词条直接删除（眼前、应急家族）
#   R3 保留复合词：只保留语义明确的复合形式（如保留"眼前利益"，删"眼前"）
# ==================================================================
