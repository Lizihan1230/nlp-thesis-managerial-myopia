# 长期视域词典 v1.0  ——  用于构建"净时间视野"(Net Time Horizon, NTH)
# ==================================================================
# 为什么要引入这一份：
#   前两轮内容效度判读发现，单纯统计"短视词"存在两个致命问题：
#   (1) 大量命中来自"短期借款""闲置募集资金暂时补充流动资金""临时股东大会"
#       等法定披露套话，与管理层视野无关；
#   (2) "短期承压，但长期向好"这类对照句式在样本中极为常见，
#       这类句式恰恰说明管理层偏重长期；按"出现短视词即为短视"计分会系统性反向收割。
#   因此把构念从"短视词的多寡"改为"**短视语 vs 长期语的净倾向**"。
# ==================================================================
