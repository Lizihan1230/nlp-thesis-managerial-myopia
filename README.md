# 管理者短视的 NLP 测度构建及其对企业长期投资的影响研究

> 2026 届本科毕业论文（设计）· **方法预演稿**
> 大连财经学院 大数据与人工智能学院 · 大数据管理与应用专业
> 样本：辽宁省 A 股上市公司 2018—2025 年年报 MD&A（64 家公司 / 442 个企业—年份观测）

本仓库是一篇**完整毕业论文预演稿**的全部可复现材料。核心问题是课程提出的那一个：

> **怎样把一段文字，变成一个能进论文的变量？**

---

## 一句话结论

> 在辽宁省 A 股样本上，**直接移植词典法的表层词频测度无法通过内容效度检验**（人工判读严格口径精确率仅 5.8%）；把构念修正为"净时间视野"后测度可获得可接受的聚合与区分效度，其与研发投入的截面负相关也符合理论预期——**但该相关在加入行业固定效应后完全消失**（β 从 −9.27 降至 −1.37，p 从 0.026 变为 0.685）。因此本文**不支持**把这类跨行业文本测度直接当作"管理层短视程度"的度量。

本文的价值不在支持某一假设，而在于完整记录了一次"测度从失败到可被检验"的过程。

## 核心结果速览

**（1）内容效度：词典法失败，且失效原因可定位**

| 词条 | v1.0 命中 | 主要误命中来源 |
|---|---|---|
| 短期 | 613 | 短期**借款**（会计科目），占 73% |
| 暂时 | 443 | 闲置募集资金**暂时补充流动资金**，占 82% |
| 临时 | 331 | **临时股东大会**、临时键合（半导体工艺） |
| 应急 | 375 | 应急**救援/体系/管理局**（行业与政务表述） |
| 眼前 | 17 | **眼前节**（眼科医学名词） |

经邻近语境剔除后命中下降 82.9%，但人工判读的严格口径精确率仍仅 **5.77%**（52 条抽样），而长期视域词典精确率达 **81.25%**（32 条抽样）。

**（2）三路测度：谁能用，谁不能用**

| 路线 | 能否提供有效测度 | 受限原因 |
|---|---|---|
| 词典法 | 否（表层形式） | 语境迁移失败：本土年报中短视语几乎不承载短视语义 |
| 词嵌入 | 仅作校验 | **语料规模不足**：约 240 万词，近邻词为随机碎片 |
| LDA | 否 | **目标语义过于稀疏**（占比 ≈0.014%），无法独立成题 |

**（3）效应来源诊断——本文最重要的结果**

| 设定 | β | 聚类稳健 t | p | 调整 R² |
|---|---|---|---|---|
| 仅纳入 NTH | −9.267 | −2.23 | 0.026 | 0.022 |
| + 财务与篇幅控制 | −6.317 | −1.72 | 0.085 | 0.232 |
| + 年份固定效应 | −7.964 | −2.14 | 0.032 | 0.237 |
| **+ 行业固定效应** | **−1.372** | **−0.41** | **0.685** | 0.635 |
| + 企业固定效应 | −0.931 | −0.65 | 0.515 | 0.907 |

**（4）篇幅陷阱对照**：用 ln(1+命中数) 而不除篇幅时，测度与披露篇幅的 Spearman ρ=+0.300，回归显示"短视越多、研发越高"（β=+1.639，p=0.013）；控制篇幅后该效应塌缩为 β=+0.016，p=0.971。**不除分母的词频测度，测到的其实是"这家公司话多不多"。**

```bash
pip install -r requirements.txt

# ① 语料获取（约 15 分钟，含全网代码扫描）
python3 scripts/01a_build_sample_frame.py
python3 scripts/01a_repair_frame.py
python3 scripts/01b_download_annual_reports.py
python3 scripts/01c_fetch_financials.py
python3 scripts/01c_repair_capex.py

python3 scripts/02_preprocessing.py

# ③ 特征提取三条路线
python3 scripts/03a_feature_dictionary.py
python3 scripts/03b_feature_word2vec.py
python3 scripts/03c_feature_lda.py

# ④⑤⑥ 指标构建、效度检验、回归分析
python3 scripts/04_measure_construction.py
python3 scripts/05a_content_validity_sample.py    # 生成待判读样本（人工判读后写回
                                                  # results/annotation_manual.csv）

python3 scripts/06_regression_analysis.py

python3 scripts/07_make_figures.py
python3 scripts/08_md_to_docx.py
```

## 三条可迁移的教训

1. **显著 ≠ 有效。** 初始词典与研发投入的 Spearman 相关达 0.156（p=0.002），"看起来是成功的"——但近九成命中并非短视语义。预测效度不能替代内容效度。
2. **模型的先进程度突破不了构念在语料中的可观测密度。** 目标语义只占万分之一点四时，换更高级的模型也无济于事。选题阶段应先做"构念可观测性"评估。
3. **行业固定效应不是可选项，而是必需品。** 在文本测度研究中，披露风格与行业的关联往往强于它与企业特征的关联。
